Features Fieldkit adds beyond Vorssaint's set (not counted above).

|---|---|---|

| Duplicate files | `duplicateFinder` | Scans chosen folders for files with identical contents (size, then a hash of the first 64 KB, then SHA-256), skipping hidden, system and online-only OneDrive files; extra copies go to the Recycle Bin. Upstream issue #3022. |

| Block apps | `blockApps` | An out-of-process window-show hook closes listed apps as they open (no administrator rights, no system-wide change); a schedule asks open ones to close normally when it starts. Upstream issue #2965. |
| Browser picker | `browserPicker` | Registers as a browser for the current user (HKCU, no administrator rights); chosen as the default in Windows' Default apps, each http(s) link shows a picker of installed browsers, or opens straight in the one a site rule names. Upstream issue #2861. |
