Fieldkit: the free toolkit for Windows 10 and 11

Fieldkit is a free, open-source toolkit that lives in the Windows notification area. It brings a per-app volume mixer, a real system monitor, keep awake, a Dynamic Island in the taskbar, clipboard history, window layouts and more than 80 other small tools into one app. Every feature is a module, so you install only what you use. There is no account, no telemetry and no subscription.

Fieldkit is the Windows port of Vorssaint, the macOS menu bar utility.

What Fieldkit does

  • Volume mixer: set the volume of each app separately.
  • System monitor: CPU, memory, disk and network at a glance.
  • Keep awake: stop the PC from sleeping while you work or present.
  • Dynamic Island: a pill in the taskbar that expands into Controls, Music, Files, Notes, Calendar, Timer, Downloads and AI Agents pages.
  • Clipboard history and window layouts: paste what you copied earlier and snap windows into place.
  • Screenshot, quick notes, dark mode, empty Recycle Bin, eject all drives and dozens more one-click controls.

Download Fieldkit

Get the installer or the portable zip from the latest release on GitHub. Neither needs .NET installed. The installed version checks for updates when it starts and asks before it updates.

Frequently asked questions

Is Fieldkit free?

Yes. It is free and open source under the GPL-3.0 licence, with no account and no subscription.

Which versions of Windows does it support?

Windows 10 (version 2004 or newer) and Windows 11.

Does Fieldkit collect data?

No account, no telemetry and no analytics. Settings stay on your PC. The network is only used for features you turn on and for the update check, which asks GitHub for the latest release.

How do I update Fieldkit?

The installed version asks whether to update to the new version when it starts. You can also download the latest release by hand.

Is there a version for Mac?

Fieldkit is for Windows. On a Mac, use Vorssaint.
